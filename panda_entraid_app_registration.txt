# additional config:
from left menu select "Token configuration"
click "+ Add optional claim"
select token type "id" and claims "email", "upn" and click add, then confirm turning on microsoft graph api permissions

# if you want to have azure ad group info in the token and be able to restict access based on groups in the app, also do this:
click "+ Add groups claim"
select "security groups"
go to "token properties by type" for all token types (ID, Access, SAML) are set it to DNSDomain\sAMAccountName
# this will cause the azure ad groups to be present in the groups claim in the oicd identity token (not sure if it's actually called a claim, but this value is definately in the json)
# you can also check "emit groups as role claims" for all token types (this will cause the azure ad groups to be present in the role claim in the oicd identity token) (if you do this, you will have to configure keycloak mappers a bit differently) (it's probably better to not do this and use the groups claim, which is the default behavior)
and click add
